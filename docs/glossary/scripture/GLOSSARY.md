# Scripture

Bible passages as content: how a passage is identified, named and read.

## Language

**Passage**:
A contiguous range of verses in one book, at any size from one verse to a whole book. The unit of Bible content.
_Avoid_: Verse (a passage may be one verse, but is not "a verse"), reference

**Verse ordinal**:
A verse's position counted across the whole canon. Passages are stored as a start and end ordinal, which makes them sortable and comparable.

**Canon**:
The set and order of books Perspectize numbers; Protestant only.

**Canonical passage name**:
The one normalised name of a passage ("John 3:16–18"), used as its content name.

**Canonical passage URL**:
The translation-free address a passage is stored under, so the same range is one content item whatever translation is read.

**Translation**:
A version of the text, chosen per reader. Never part of a passage's identity.
_Avoid_: Version (in code and picker)

**Passage text**:
The verses of a range in one translation. Only one translation's text is stored.

**Display title**:
An optional name a person gives a passage; the first one set stays.

**Lazy creation**:
A passage becomes content the first time someone writes a perspective on it; nothing is pre-created.

**Interlinear**:
The view that shows each English phrase with the original Hebrew or Greek words beneath it.

**Original-language word**:
One source word, with its transliteration, gloss, and lexicon entry.

**Strong's number**:
The standard catalogue number of an original-language word; a letter suffix marks a disambiguated sense.

**Gloss**:
The short English meaning of an original-language word.

**Segment**:
A run of English text tied to the original words it renders.

**Commentary link**:
An outbound link from a passage to a third-party commentary or reading site.
