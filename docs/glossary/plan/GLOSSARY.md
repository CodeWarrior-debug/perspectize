# Plan

What a person intends to do with content, tracked privately or publicly.

## Language

**Plan**:
A person's set of todos, shown on the Plan page.
_Avoid_: Backlog, queue

**Todo**:
One item in a plan: an action on a content item, or on a free-text name when the thing is not in Perspectize.
_Avoid_: Task, reminder

**Action**:
What a todo asks the person to do: acquire, consume, process, research, verify, compare, review, discuss, share or revisit. Presets are global; a person may add their own, visible only to them.
_Avoid_: Verb, type

**Preset action**:
An action shipped for everyone, ordered by its typical sequence in the picker.

**Todo status**:
Progress state: not started, in progress, done, dropped.

**Percent complete**:
How far along a todo is, 0–100.

**Priority**:
How much a todo matters, on the rating scale.

**Start date / finished date / due date**:
When work began, when it ended, and the target. Date only, no time.

**Todo list**:
A named, ordered group of a person's todos. A todo is in at most one list.
_Avoid_: Board, folder

**List position**:
A todo's place within its list.

**Open todo**:
A todo not yet done or dropped. A person can have only one open todo per content item and action; a finished one does not block starting the same action again.

**Todo privacy**:
Each todo and each list carries its own privacy, independent of the other.
