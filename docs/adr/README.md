# Architecture Decision Records

Short records of decisions that are costly to rediscover, especially decisions **not** to build something, and why. One file per decision: `NNNN-kebab-title.md`, numbered in order and never reused.

Each record has **Status** (Proposed / Accepted / Superseded by NNNN), **Date**, **Context**, **Decision**, **Consequences**, and, for deferrals, **Revisit when**. To change a decision, add a new ADR that supersedes the old one rather than rewriting it.
