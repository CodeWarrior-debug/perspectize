# Subscriber listening test with real accounts

Type: `wayfinder:task` (HITL) · Status: open · Blocked by: none · Claimed by: none

## Question

Which providers actually give a signed-in subscriber full, ad-free tracks inside a third-party page? Only a human with real accounts can answer, and the answer decides the first embedded player and whether sign-in is needed.

## Checklist for the owner (about 20 minutes)

1. **YouTube Premium:** signed into YouTube in Chrome, open a test page embedding one official audio track twice — once from `youtube.com` and once from `youtube-nocookie.com`. Note whether ads or a "get Premium" notice appear in each.
2. **Apple Music:** while signed out of Apple Music, open `embed.music.apple.com` for a track. Note whether you get 30-second previews. Then signed in with your subscription, note whether the same embed plays the full track.
3. **Amazon Music:** only check which track URL formats open correctly on desktop and mobile. There is no web player to test.
4. **Spotify:** skipped (no account). Spotify stays a link plus its standard embed.

Record results as a short list in the resolution.
