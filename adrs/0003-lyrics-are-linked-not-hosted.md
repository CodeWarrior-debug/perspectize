# Lyrics are linked, not hosted

Perspectize shows a lyrics link (to LRCLIB's page, or a search page) only when a lookup says lyrics exist, and never stores or displays lyric text. Showing lyrics needs a licence; Genius's API does not return text and scraping violates its terms, and free tiers of licensed providers appear non-commercial.

An in-app lyrics tab backed by a licensed provider (for example Musixmatch's embed) stays a possible later upgrade if its terms and cost turn out to be acceptable. That is not part of the first version.
