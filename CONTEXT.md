# Perspectize

A platform for storing, refining, and sharing perspectives on content. This glossary covers the audio-track area; add other areas as their language is settled.

## Language

**Audio track**:
One piece of recorded music, held as a single item users write perspectives about, no matter which provider it was found on.
_Avoid_: Song, music, YouTube Music track

**Recording**:
The abstract performance an audio track stands for, identified across providers by its ISRC where one is known.
_Avoid_: Master, version

**Provider**:
A service that can play or describe an audio track: YouTube Music, Spotify, Apple Music, Amazon Music, Deezer, SoundCloud.
_Avoid_: Platform, source, service

**Listen link**:
A provider's own URL for an audio track, shown so a user can open and play it there.
_Avoid_: Outbound link, related media

**Embedded listening**:
Playing an audio track inside Perspectize through a provider's official player.
_Avoid_: Streaming (Perspectize never serves audio itself)

**Subscriber listening**:
Embedded listening where the user has signed in with their own provider subscription, so they hear full tracks without ads or preview limits.
_Avoid_: Premium mode, ad-free mode

**Matcher**:
The part that finds an audio track's other listen links from one pasted link or one ISRC.
_Avoid_: Resolver, aggregator

**Lyrics link**:
A link to where a track's lyrics can be read. Perspectize does not host or display lyric text.
_Avoid_: Lyrics (alone, which suggests we show the text)
