<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 1: Verify Capacitor POC in iOS Simulator</name>
  <what-built>
    Capacitor integration with the existing SvelteKit app. The app should load in iOS Simulator via Xcode, showing the Activity table with all existing functionality.
  </what-built>
  <how-to-verify>
    **Pre-flight (Claude runs these before checkpoint):**
    ```bash
    cd frontend
    pnpm run build
    npx cap sync
    npx cap open ios
    ```
    This opens Xcode with the Perspectize project.

    **User verification steps:**

    1. **Build and Run in Xcode:**
       - In Xcode, select an iPhone simulator (e.g., iPhone 16)
       - Press Cmd+R or click the Play button to build and run
       - Wait for the app to launch in Simulator

    2. **Verify app loads:**
       - [ ] App launches without white screen
       - [ ] Navy header (#1a365d) is visible at top
       - [ ] Activity table (AG Grid) renders with data rows
       - [ ] "Add Video" button is visible in header

    3. **Verify navigation:**
       - [ ] Tap on table rows — no crashes or white screens
       - [ ] Scroll the AG Grid table — smooth performance
       - [ ] Pagination controls work (next/prev page)

    4. **Verify GraphQL:**
       - [ ] Data loads in the Activity table (proves GraphQL API calls work from WebView)
       - [ ] If no data appears, check if the backend is running and accessible from the Simulator's network

    5. **Verify AG Grid performance:**
       - [ ] Table scrolling is smooth (not janky or laggy)
       - [ ] Column sorting works (tap column headers)
       - [ ] Filters work (if floating filters are visible)

    6. **Note any issues:**
       - Record any visual glitches, performance problems, or broken functionality
       - Check Xcode console for errors/warnings

    **PWA verification (separate — on web):**
    7. Run `cd frontend && pnpm run preview` and open in Chrome
       - [ ] Open Chrome DevTools > Application > Manifest
       - [ ] Verify manifest shows "Perspectize" with navy theme color
       - [ ] Check for installable prompt (may need HTTPS for full test)

    **If iOS Simulator is not available** (no Xcode installed):
    - Skip iOS verification steps 1-6
    - Test Android instead: `npx cap open android` (requires Android Studio)
    - Or test web build only: `pnpm run preview` and verify app works
    - Note in resume signal what was/wasn't testable
  </how-to-verify>
  <resume-signal>
    Type "approved" with any notes about issues found, or describe problems to fix.
    Include: which platform was tested (iOS Simulator, Android Emulator, or web-only), any performance observations, any visual issues.
  </resume-signal>
