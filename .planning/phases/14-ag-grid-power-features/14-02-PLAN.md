<objective>
Add a column visibility picker dropdown to the GridToolbar, allowing users to show/hide columns without developer tools.

Purpose: Users currently have no way to control which columns are visible. Some columns (like Tags, Description) may be irrelevant to certain users. A dropdown with checkboxes per column gives users control over their view.

Output: A ColumnVisibilityPicker.svelte component rendered inside GridToolbar as a Columns dropdown button. Bidirectional sync between checkbox state and AG Grid column visibility, with localStorage persistence.
</objective>
