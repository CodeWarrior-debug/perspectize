1. Create `frontend/src/lib/services/gridStateManager.ts`:
   - Define localStorage keys with `perspectize:activityTable:` namespace (filters, columns, pageSize)
   - Implement `saveFilterState(gridApi)` — gets filter model, serializes to localStorage
   - Implement `loadFilterState(gridApi)` — reads from localStorage, applies via `gridApi.setFilterModel()`
   - Implement `saveColumnState(gridApi)` — gets column state, serializes to localStorage
   - Implement `loadColumnState(gridApi)` — reads from localStorage, applies via `gridApi.applyColumnState()`
   - Implement `clearAllState()` — removes all perspectize localStorage keys
   - Implement `createDebouncedSaver(fn, delay=1000)` — returns debounced version of save function
   - Handle JSON parse errors gracefully (corrupted localStorage → silently clear and continue)
   - Export `DEFAULT_COLUMN_STATE` constant matching current ActivityTable columnDefs defaults

2. Create `frontend/src/lib/components/GridToolbar.svelte`:
   - Accept props: `gridApi` (AG Grid API instance)
   - Reactive state: `hasActiveFilters` ($state), `filterCount` ($state)
   - Update filter state on `onFilterChanged` callback from parent
   - Clear Filters button: calls `gridApi.setFilterModel(null)` + clears localStorage filter state
   - Show filter count badge next to Clear Filters when filters active (use shadcn Badge or inline span)
   - Export CSV button: calls `gridApi.exportDataAsCsv()` with timestamped filename
   - Reset button: calls `clearAllState()` + `gridApi.resetColumnState()` + `gridApi.setFilterModel(null)`
   - Layout: `flex items-center gap-2 px-2 py-1.5 bg-muted/50 rounded-t-lg border-b`
   - Use lucide-svelte icons: FilterX, Download, RotateCcw
   - All buttons use shadcn Button component with variant="ghost" size="sm"

3. Update `frontend/src/lib/components/ActivityTable.svelte`:

   - In onGridReady: call `loadFilterState(gridApi)` and `loadColumnState(gridApi)`
   - Add onFilterChanged handler: update toolbar filter state + debounced save to localStorage
   - Add onColumnVisible/onColumnMoved/onSortChanged handlers: debounced save column state
   - Wrap grid + toolbar in `flex flex-col gap-0` container
