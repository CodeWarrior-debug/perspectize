## Convention-Based Sort Mapping

After denormalization, all sortable fields are real GORM struct fields with corresponding
indexed DB columns. This eliminates the `buildContentSortRules` switch statement and
`SQLRepr`/dummy field workarounds.

**Pattern:** GraphQL enum value → GORM field name → DB column (automatic via GORM naming)

```go
// Replace switch statement with declarative map
var contentSortKeyMap = map[domain.ContentSortBy]string{
    domain.ContentSortByName:         "Name",         // → name
    domain.ContentSortByViewCount:    "ViewCount",    // → view_count
    domain.ContentSortByLikeCount:    "LikeCount",    // → like_count
    domain.ContentSortByPublishedAt:  "PublishedAt",  // → published_at
    domain.ContentSortByCreatedAt:    "CreatedAt",    // → created_at
    domain.ContentSortByUpdatedAt:    "UpdatedAt",    // → updated_at
    domain.ContentSortByDuration:     "Length",       // → length
    domain.ContentSortByChannelTitle: "ChannelTitle", // → channel_title
    domain.ContentSortByContentType:  "ContentType",  // → content_type
}

func buildContentSortRules(sortBy domain.ContentSortBy, order domain.SortOrder) []paginator.Rule {
    paginatorOrder := paginator.DESC
    if order == domain.SortOrderAsc {
        paginatorOrder = paginator.ASC
    }
    key := contentSortKeyMap[sortBy]
    if key == "" {
        key = "CreatedAt"
    }
    return []paginator.Rule{
        {Key: key, Order: paginatorOrder},
        {Key: "ID", Order: paginatorOrder},
    }
}
```

**Cleanup:** Remove dummy fields (`ViewCount`, `LikeCount`, `PublishedAt` with `gorm:"-"`)
from ContentModel — they become real columns.

**Frontend mirror:** AG Grid colId → GraphQL enum is already a map (`SORT_FIELD_MAP`).
Add entries for new sort fields: `duration: 'DURATION'`, `channel: 'CHANNEL_TITLE'`,
`type: 'CONTENT_TYPE'`.
</convention>
