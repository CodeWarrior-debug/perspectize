```go
func parseIntSafe(s string) int {
    if s == "" {
        return 0
    }
    val, err := strconv.Atoi(s)
    if err != nil {
        return 0
    }
    return val
}
```

**Why parseIntSafe:** YouTube API returns statistics as strings (e.g., "1234567"). This safely converts to int with zero fallback.
