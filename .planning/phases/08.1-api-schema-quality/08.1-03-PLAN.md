```sql
ALTER TABLE users
    ADD CONSTRAINT users_unique_username UNIQUE (username),
    ADD CONSTRAINT users_unique_email UNIQUE (email);

-- Add composite unique constraint on perspectives table
-- Prevents duplicate perspective claims (same user claiming same content twice)
ALTER TABLE perspectives
    ADD CONSTRAINT perspectives_unique_user_content UNIQUE (user_id, content_id);
```

**000007_add_unique_constraints.down.sql:**
```sql
-- Remove unique constraints
ALTER TABLE perspectives DROP CONSTRAINT IF EXISTS perspectives_unique_user_content;
ALTER TABLE users DROP CONSTRAINT IF EXISTS users_unique_email;
ALTER TABLE users DROP CONSTRAINT IF EXISTS users_unique_username;
```

**Migration notes:**
- Named constraints for clear error messages and easier debugging
- Composite constraint on (user_id, content_id) allows same user to have multiple perspectives, but not duplicate claims
- content_id can be NULL (perspectives not yet linked to content) — UNIQUE constraint allows multiple NULLs

Add isUniqueViolation helper function to detect PostgreSQL unique constraint violations.

Add to helpers.go (after existing helper functions):

```go
import (
    // ... existing imports ...
    "errors"
    "github.com/jackc/pgx/v5/pgconn"
)

// isUniqueViolation checks if error is a PostgreSQL unique constraint violation.
// PostgreSQL error code 23505 = unique_violation
func isUniqueViolation(err error) bool {
    var pgErr *pgconn.PgError
    if errors.As(err, &pgErr) {
        return pgErr.Code == "23505"
    }
    return false
}
```

**Why needed:** GORM doesn't provide standard error types for constraint violations (RESEARCH.md Pattern 2). Use database-specific error code checking via pgconn.PgError.

**Error code 23505:** PostgreSQL standard error code for unique constraint violations (documented in PostgreSQL error codes appendix).

This helper will be used in service layer Create operations to distinguish unique violations from other errors.

Updated Create() method (remove read-then-write check, handle constraint violation):
```go
func (s *UserService) Create(ctx context.Context, input portservices.CreateUserInput) (*domain.User, error) {
    // Validate username
    if input.Username == "" {
        return nil, fmt.Errorf("%w: username is required", domain.ErrInvalidInput)
    }

    // Create user (DB constraint prevents duplicates)
    user := &domain.User{
        Username: input.Username,
        Email:    input.Email,
    }

    created, err := s.repo.Create(ctx, user)
    if err != nil {
        // Check if error is unique constraint violation
        if isUniqueViolation(err) {
            return nil, fmt.Errorf("%w: username or email already taken", domain.ErrAlreadyExists)
        }
        return nil, fmt.Errorf("failed to create user: %w", err)
    }

    return created, nil
}
```
