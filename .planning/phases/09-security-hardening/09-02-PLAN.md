<task type="auto">
  <name>Implement full @owner directive with resource ownership checks</name>
  <files>
    backend/internal/adapters/graphql/directives/auth.go
  </files>
  <action>
    Update directives/auth.go Owner() implementation:

    1. Inject services into DirectiveRoot constructor:
       - NewDirectiveRoot(contentService, perspectiveService) takes services as params
       - Store as struct fields

    2. Owner directive implementation:
       - Extract authenticated user ID via ForContext()
       - Extract resource ID from fieldContext.Args[idField]
       - Determine resource type based on mutation name (e.g., "deletePerspective" -> perspective, "deleteContent" -> content)
       - Look up resource via service.GetByID()
       - Check if resource.UserID == authenticatedUserID
       - Return error if not owner: "access denied: you can only modify your own resources"
       - Call next(ctx) if owner

    Example:
    ```go
    func (d *DirectiveRoot) Owner(ctx context.Context, obj interface{}, next graphql.Resolver, idField string) (interface{}, error) {
        userID, authenticated := middleware.ForContext(ctx)
        if !authenticated {
            return nil, fmt.Errorf("access denied: authentication required")
        }

        fc := graphql.GetFieldContext(ctx)
        resourceIDArg, ok := fc.Args[idField]
        if !ok {
            return nil, fmt.Errorf("missing %s argument", idField)
        }

        resourceID, ok := resourceIDArg.(int)
        if !ok {
            return nil, fmt.Errorf("invalid %s type", idField)
        }

        // Determine resource type from mutation name
        if strings.Contains(fc.Field.Name, "Perspective") {
            perspective, err := d.perspectiveService.GetByID(ctx, resourceID)
            if err != nil {
                return nil, err
            }
            if perspective.UserID != userID {
                return nil, fmt.Errorf("access denied: you can only modify your own perspectives")
            }
        } else if strings.Contains(fc.Field.Name, "Content") {
            content, err := d.contentService.GetByID(ctx, resourceID)
            if err != nil {
                return nil, err
            }
            if content.UserID != userID {
                return nil, fmt.Errorf("access denied: you can only modify your own content")
            }
        }

        return next(ctx)
    }
    ```

    This addresses C-01 authorization: users can only modify their own data.
