<task type="auto">
  <name>Create authentication middleware for HTTP layer</name>
  <files>
    backend/internal/adapters/web/middleware/auth.go
  </files>
  <action>
    Create middleware/auth.go with:

    1. Context key: `const userContextKey contextKey = "user"`

    2. AuthMiddleware(authService AuthService) func(http.Handler) http.Handler:
       - Extract token from httpOnly cookie "auth_token"
       - If no cookie: call next() (unauthenticated request allowed)
       - If cookie exists: call authService.ValidateToken()
       - If valid: store user ID in context via context.WithValue(r.Context(), userContextKey, claims.UserID)
       - If invalid: call next() (treat as unauthenticated, no error response)

    3. ForContext(ctx context.Context) (int, bool):
       - Helper to extract user ID from context in resolvers/directives
       - Returns (userID, authenticated bool)

    Per research Pattern 1: Middleware authenticates, directives authorize. Never block unauthenticated requests in middleware.
  </action>
  <verify>
    go build ./internal/adapters/web/middleware/
    grep -q "AuthMiddleware" backend/internal/adapters/web/middleware/auth.go
    grep -q "ForContext" backend/internal/adapters/web/middleware/auth.go
  </verify>
  <done>Auth middleware extracts JWT from cookie, stores user context</done>
</task>

  <action>
    1. Add directives to schema.graphql:
       ```graphql
       directive @auth on FIELD_DEFINITION
       directive @owner(idField: String!) on FIELD_DEFINITION
       ```

    2. Create directives/auth.go with DirectiveRoot:
       - Auth(ctx, obj, next) method:
         - Call middleware.ForContext(ctx) to get userID
         - If not authenticated: return nil, fmt.Errorf("access denied: authentication required")
         - If authenticated: return next(ctx)

       - Owner(ctx, obj, next, idField) method:
         - Call middleware.ForContext(ctx)
         - If not authenticated: return error
         - Extract resource ID from fieldContext.Args[idField]
         - Check ownership (for now, just validate authenticated - full ownership in Plan 02)
         - Return next(ctx)

    3. Run `make graphql-gen` to regenerate schema with directives

    Per research Pattern 2: Directive-based authorization visible in schema, runs after middleware authentication
  </action>
