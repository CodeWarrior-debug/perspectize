<task type="auto">
  <name>Create security headers middleware</name>
  <files>
    backend/internal/adapters/web/middleware/secureheaders.go
  </files>
  <action>
    Create secureheaders.go:

    ```go
    package middleware

    import (
        "net/http"
        "os"

        "github.com/unrolled/secure"
    )

    // SecureHeaders returns middleware setting security headers
    func SecureHeaders() func(http.Handler) http.Handler {
        isDevelopment := os.Getenv("APP_ENV") != "production"

        secureMiddleware := secure.New(secure.Options{
            // HSTS: enforce HTTPS for 1 year, include subdomains (only in production)
            STSSeconds:           31536000,
            STSIncludeSubdomains: true,
            STSPreload:           true,

            // Prevent MIME sniffing
            ContentTypeNosniff: true,

            // Prevent clickjacking
            FrameDeny: true,

            // XSS protection (legacy browsers)
            BrowserXssFilter: true,

            // Content Security Policy for backend responses
            ContentSecurityPolicy: "default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' https://i.ytimg.com https://yt3.ggpht.com; connect-src 'self'; font-src 'self';",

            // Only enforce in production (development allows http://localhost)
            IsDevelopment: isDevelopment,
        })

        return secureMiddleware.Handler
    }
    ```

    Per research Pattern 4: Security headers with HSTS, X-Content-Type-Options, X-Frame-Options, CSP. Development mode disables HSTS to allow localhost.

    This addresses M-14: Security headers (HSTS, X-Content-Type-Options, X-Frame-Options).
  </action>
  <verify>

    grep -q "ContentTypeNosniff" backend/internal/adapters/web/middleware/secureheaders.go

<task type="auto">
  <name>Enhance frontend CSP meta tag</name>
  <files>
    frontend/src/app.html
  </files>
  <action>
    Update CSP meta tag in app.html to be more restrictive:

    Current (from Phase 7.3):
    ```html
    <meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://i.ytimg.com https://yt3.ggpht.com; connect-src 'self' http://localhost:8080 https://*.sevalla.app https://api.perspectize.com; font-src 'self' data:;">
    ```

    Enhanced version:
    ```html
    <meta http-equiv="Content-Security-Policy" content="
      default-src 'self';
      script-src 'self' 'unsafe-inline';
      style-src 'self' 'unsafe-inline';
      img-src 'self' data: https://i.ytimg.com https://yt3.ggpht.com;
      connect-src 'self' http://localhost:8080 https://*.sevalla.app https://api.perspectize.com;
      font-src 'self' data:;
      frame-ancestors 'none';
      base-uri 'self';
      form-action 'self';
    ">
    ```

    Changes:
    - Add `frame-ancestors 'none'` to prevent clickjacking
    - Add `base-uri 'self'` to prevent base tag injection
    - Add `form-action 'self'` to restrict form submission targets
    - Keep 'unsafe-inline' for script-src and style-src (Svelte generates inline scoped CSS)

    This addresses H-25: Enhanced CSP on frontend.

    Note: Backend CSP in secureheaders.go is simpler (backend serves only GraphQL JSON, no HTML/CSS).
  </action>
