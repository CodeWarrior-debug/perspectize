## Decisions Made

- JSONB filter performance is O(n) without indexes — acceptable for current scale (<1000 items). Phase 11 (Database Optimization) will add indexes.
- Tag search uses `(tags)::text ILIKE` which casts entire JSONB array to text. Simple and correct for MVP; can upgrade to `jsonb_array_elements_text` subquery or `@>` operator later.
- ISO 8601 date strings can be compared lexicographically for publishedAt since they sort correctly as strings.
