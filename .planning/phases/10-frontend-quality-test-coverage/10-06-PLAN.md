Install Knip and create configuration:

```bash
cd frontend
pnpm add -D knip
```

Create `frontend/.knip.json`:

```json
{
  "$schema": "https://unpkg.com/knip@latest/schema.json",
  "entry": [
    "src/routes/**/*.svelte",
    "src/routes/**/*.ts",
    "src/app.html",
    "src/hooks.client.ts",
    "vite.config.ts",
    "svelte.config.js"
  ],
  "project": [
    "src/**/*.{ts,svelte}"
  ],
  "ignore": [
    "src/lib/graphql/**",
    "tests/**",
    "coverage/**"
  ],
  "ignoreDependencies": [
    "@sveltejs/adapter-static",
    "@sveltejs/vite-plugin-svelte"
  ]
}
```

Add script to `package.json`:
```json
{
  "scripts": {
    "knip": "knip"
  }
}
```

This configures Knip to:
- Start from SvelteKit entry points (routes, hooks)
- Scan all TypeScript and Svelte files
- Ignore generated code (graphql/) and test files
- Find unused exports, dependencies, and config

Run Knip to see current dead code:
```bash
cd frontend
pnpm run knip
```

Expected findings (from planning context):
- Potentially unused stores (selectedUserId if not consumed)
- Unused type guards
- Unused exports in utils/

DO NOT automatically delete findings yet — this task only sets up detection. Cleanup decisions require human review.

Enhance existing `tests/unit/formatting.test.ts` (or create if doesn't exist) to test tooltip utilities.

Add tests for `formatTags`, `truncateDescription`, and tooltip component exports:

```typescript
import { describe, test, expect } from 'vitest';
import {
  formatTags,
  truncateDescription,
  formatCount,
  formatCountExact,
  formatPublishDate
} from '$lib/utils/formatting';

describe('formatTags', () => {
  test('returns empty string for null', () => {
    expect(formatTags(null)).toBe('');
  });

  test('returns empty string for undefined', () => {
    expect(formatTags(undefined)).toBe('');
  });

  test('returns empty string for empty array', () => {
    expect(formatTags([])).toBe('');
  });

  test('formats single tag', () => {
    expect(formatTags(['music'])).toBe('music');
  });

  test('formats multiple tags with comma separation', () => {
    expect(formatTags(['music', 'guitar', 'tutorial'])).toBe('music, guitar, tutorial');
  });

  test('handles tags with spaces', () => {
    expect(formatTags(['classical music', 'jazz'])).toBe('classical music, jazz');
  });
});

describe('truncateDescription', () => {
  test('returns empty string for null', () => {
    expect(truncateDescription(null)).toBe('');
  });

  test('returns empty string for undefined', () => {
    expect(truncateDescription(undefined)).toBe('');
  });

  test('returns empty string for empty string', () => {
    expect(truncateDescription('')).toBe('');
  });

  test('returns short text unchanged', () => {
    const text = 'Short description';
    expect(truncateDescription(text)).toBe(text);
  });

  test('truncates long text at 100 characters', () => {
    const longText = 'a'.repeat(150);
    const result = truncateDescription(longText);
    expect(result.length).toBe(103); // 100 chars + '...'
    expect(result.endsWith('...')).toBe(true);
  });

  test('truncates at word boundary if possible', () => {
    const text = 'This is a very long description that should be truncated at a reasonable word boundary to avoid cutting words in half and making the text hard to read for users';
    const result = truncateDescription(text);
    expect(result.endsWith('...')).toBe(true);
    expect(result.length).toBeLessThanOrEqual(103);
  });
});

describe('formatCount', () => {
  test('returns "--" for null', () => {
    expect(formatCount(null)).toBe('--');
  });

  test('returns number as string for values < 1000', () => {
    expect(formatCount(500)).toBe('500');
    expect(formatCount(0)).toBe('0');
  });

  test('formats thousands with K suffix', () => {
    expect(formatCount(1200)).toBe('1.2K');
    expect(formatCount(45600)).toBe('45.6K');
  });

  test('formats millions with M suffix', () => {
    expect(formatCount(1200000)).toBe('1.2M');
    expect(formatCount(3400000)).toBe('3.4M');
  });
});

describe('formatCountExact', () => {
  test('returns "--" for null', () => {
    expect(formatCountExact(null)).toBe('--');
  });

  test('returns exact number with comma separators', () => {
    expect(formatCountExact(1234567)).toBe('1,234,567');
    expect(formatCountExact(123)).toBe('123');
    expect(formatCountExact(0)).toBe('0');
  });
});

describe('formatPublishDate', () => {
  test('returns "--" for null', () => {
    expect(formatPublishDate(null)).toBe('--');
  });

  test('formats ISO date string to locale date', () => {
    const isoDate = '2024-01-15T10:30:00Z';
    const result = formatPublishDate(isoDate);
    // Result format depends on locale, just verify it's not empty and not "--"
    expect(result).not.toBe('--');
    expect(result.length).toBeGreaterThan(0);
  });

  test('handles invalid date string gracefully', () => {
    const result = formatPublishDate('invalid-date');
    // Should return some fallback (check implementation)
    expect(result).toBeDefined();
  });
});
```

This covers all the uncovered formatting utilities. The tests verify:

- Single-item and multi-item formatting
- Truncation logic (character limit, ellipsis)
- Number formatting (K/M suffixes, comma separators)
- Date formatting (valid ISO, invalid input)
