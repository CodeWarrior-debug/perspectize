## Decisions Made
- Category column positioned after Type (colId order: perspectize, item, type, category, duration, ...) for logical grouping of metadata columns
- Popover rendered outside the AG Grid DOM with fixed positioning to avoid AG Grid portal/clipping issues (pitfall #3 from research)
- Backdrop button pattern (invisible fixed inset-0 z-40) for dismissal instead of click-outside event listener -- simpler and avoids event propagation edge cases
- Category column not sortable/filterable per CONTEXT.md deferral -- sorting/filtering by category deferred to future phase
