## Decisions Made
- Used GORM `clause.OnConflict` for atomic category upsert by `wikidata_qid` -- matches existing GetOrCreateByURL pattern
- Content.primaryCategory uses gqlgen field resolver (lazy loading) to avoid N+1 on list queries -- category is only fetched when the field is requested
- CategoryService applies defaults for empty language ("en") and zero limit (10) in SearchWikidata, keeping resolver logic thin
