## Decisions Made
- CategoryTypeahead is a "dumb" search component that calls onSelect callback rather than calling the mutation itself -- keeps it reusable and testable, parent handles mutation
- 300ms debounce with 2-char minimum prevents excessive Wikidata API calls (pitfall #6 from research)
- keepPreviousData from TanStack Query prevents flicker during typing for smooth typeahead UX
- 5-minute staleTime caches repeated Wikidata searches to reduce API load
