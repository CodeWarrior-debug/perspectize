## Decisions Made
- Used flat `label` and `description` fields from wbsearchentities response (not the nested `display` object) per Wikidata API documentation
- EntityType hardcoded to "item" since wbsearchentities type=item parameter only returns items
- Simple for-loop retry with exponential backoff (1s, 2s) instead of external retry library -- keeps dependencies minimal
- Custom APIError type to enable retryable check based on HTTP status code (429, 5xx)
