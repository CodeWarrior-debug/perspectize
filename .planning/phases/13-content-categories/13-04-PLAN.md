<tasks>
1. Create `backend/internal/core/ports/ai_service.go`:
   - Define `CategorySuggestion` struct: CategorySlug string, Confidence float64, Reasoning string
   - Define `AIService` interface: `SuggestCategory(ctx, title string, description string, tags []string) (*CategorySuggestion, error)`

2. Create `backend/internal/adapters/ai/claude_client.go`:
   - `ClaudeClient` struct with Anthropic API client and category list
   - Implement `SuggestCategory`:
     - Build prompt with list of 20 category slugs and names
     - Send title + description + tags to Claude Haiku 3.5
     - Parse JSON response: `{"category_slug": "...", "confidence": 0.0-1.0, "reasoning": "..."}`
     - Return CategorySuggestion
   - Handle API errors gracefully (return nil suggestion, not error)
   - Handle low confidence (<0.5) by returning suggestion with low confidence flag

3. Update `backend/schema.graphql`:
   - Add `CategorySuggestion` type: category (Category!), confidence (Float!), reasoning (String)
   - Add `suggestCategory(contentId: IntID!): CategorySuggestion` query

4. Run `make graphql-gen`

5. Update `backend/internal/core/services/content_service.go`:
   - Add AIService dependency (optional — nil means auto-categorization disabled)
   - After content creation, if no category set and AIService available:
     - Call SuggestCategory with content title, description, tags
     - If confidence >= 0.7, auto-assign category (user can change later)
     - If confidence < 0.7, store suggestion but don't auto-assign

6. Implement `suggestCategory` resolver:
   - Load content by ID
   - Call AIService.SuggestCategory with content fields
   - Map category slug to Category object via CategoryRepository.GetBySlug
   - Return CategorySuggestion

7. Wire ClaudeClient in `cmd/server/main.go`:
   - Instantiate only if ANTHROPIC_API_KEY env var is set
   - Pass as optional AIService to ContentService

8. Write tests in `backend/internal/adapters/ai/claude_client_test.go`:
   - TestSuggestCategory_ConstructsCorrectPrompt (verify all 20 categories in prompt)
   - TestSuggestCategory_ParsesValidResponse
   - TestSuggestCategory_HandlesAPIError (returns nil, not error)
   - TestSuggestCategory_HandlesInvalidJSON (returns nil)
   - TestSuggestCategory_HandlesLowConfidence
   - Mock HTTP client for all tests (don't call real API)

9. Update `frontend/src/lib/components/AddVideoPopover.svelte`:
   - After successful video add, call suggestCategory query with new content ID
   - Display suggestion as: "Suggested: 🎮 Games (87% confident)" with Accept/Change buttons
   - Accept button calls updateContent mutation to set category
   - Change button opens CategoryPicker

10. Run `go test ./...` in backend/ and `pnpm run test:run` in frontend/
</tasks>
