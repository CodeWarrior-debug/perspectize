1. Update `frontend/src/lib/services/youtubeApi.ts`:
   - Extend SearchParams interface with optional fields:
     - `videoDuration?: 'short' | 'medium' | 'long'`
     - `publishedAfter?: string` (ISO 8601)
     - `order?: 'relevance' | 'date' | 'viewCount' | 'rating'`
   - Update fetchYouTubeSearch to set URL params when present
   - Export `SearchFilters` type for filter state

2. Create `frontend/src/lib/components/discover/FilterBar.svelte`:
   - Props: `filters` as bindable (SearchFilters type)
   - Duration select:
     - Options: Any duration, Under 4 minutes (short), 4-20 minutes (medium), Over 20 minutes (long)
   - Upload Date select:
     - Options: Any time, Last hour, Today, This week, This month, This year
     - Calculate publishedAfter ISO string from relative option
   - Sort Order select:
     - Options: Relevance, Upload date, View count, Rating
   - Clear Filters button:
     - Only visible when any filter differs from defaults
     - Resets all to: duration=undefined, date=undefined, order='relevance'
   - Use shadcn Select components for consistent styling

3. Update `frontend/src/routes/discover/+page.svelte`:
   - Add filters state: `let filters = $state({ duration: undefined, publishedAfter: undefined, order: 'relevance' })`
   - Include filters in TanStack Query key: `youtubeKeys.search(debouncedQuery, filters)`
   - Pass filters to fetchYouTubeSearch
   - Reset page token and accumulated results when filters change
   - Render FilterBar between SearchBar and VideoResultsGrid, conditionally: only when `view === 'search'`

4. Run `pnpm run test:run` in frontend/ to verify
