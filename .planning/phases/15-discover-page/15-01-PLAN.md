<objective>
Create the Discover page with YouTube search, a Trending default view, result display, and one-click add to library.

Purpose: Users currently must find videos on YouTube externally, copy URLs, and paste them into Perspectize. This plan creates a /discover route with in-app YouTube search, reducing the add flow from 4+ clicks to 2 (search + click add). Before a query is entered, the page shows YouTube's Trending chart rather than an empty state. This is the MVP search experience — category Browse is deferred (see 15-03, skipped) but the page is structured with an internal view state so Browse can be added later without a rework.

Output: /discover route with SearchBar (debounced, placeholder "Search Content Sources..."), a Trending default view ("Showing Trending Content" label + grid), VideoResultsGrid with thumbnails and metadata, VideoCard with Add to Library button, Load More pagination, and Header navigation update.
</objective>

1. Create `frontend/src/lib/services/youtubeApi.ts`:
   - Define TypeScript interfaces: SearchParams, SearchResponse, SearchResultItem, TrendingResponse
   - Define a common `VideoItem` type that both search and trending results are normalized into (id, title, channelTitle, publishedAt, description, thumbnails) — write a small adapter function per source (`toVideoItem(searchResultItem)`, `toVideoItem(trendingItem)`) so downstream components never see the raw API shape
   - Implement `fetchYouTubeSearch(params: SearchParams): Promise<SearchResponse>`
     - Builds URL: `https://www.googleapis.com/youtube/v3/search`
     - Sets: `part=snippet`, `type=video`, `key=VITE_YOUTUBE_API_KEY`
     - Maps params: q, maxResults (25), pageToken, order
     - Throws on non-OK response with status code
   - Implement `fetchYouTubeTrending(regionCode: string = 'US', pageToken?: string): Promise<TrendingResponse>`
     - Builds URL: `https://www.googleapis.com/youtube/v3/videos`
     - Sets: `part=snippet,contentDetails`, `chart=mostPopular`, `regionCode`, `key=VITE_YOUTUBE_API_KEY`
     - Throws on non-OK response with status code
   - Export query key factory:
     ```typescript
     export const youtubeKeys = {
       all: ['youtube'] as const,
       searches: () => [...youtubeKeys.all, 'search'] as const,
       search: (query: string, filters?: SearchFilters) =>
         [...youtubeKeys.searches(), query, filters] as const,
       trending: (regionCode: string = 'US') =>
         [...youtubeKeys.all, 'trending', regionCode] as const,
     };
     ```
