# Requirements: Perspectize v1.1 Platform Expansion

**Defined:** 2026-02-16
**Core Value:** Users can easily submit their perspective on content (YouTube, books, articles) and browse others' perspectives in a way that keeps them in control.

---

## v1.1 Requirements

### Database Optimization (DBOPT)

- [ ] **DBOPT-01**: JSONB response column trimmed to essential paths only (40-60% storage reduction)
- [ ] **DBOPT-02**: Frequently queried JSONB fields promoted to dedicated columns (view_count, like_count, channel_title, published_at, tags, description)
- [ ] **DBOPT-03**: Composite indexes on promoted columns for keyset pagination
- [ ] **DBOPT-04**: Server-side sorting works for all column types (text, number, date)
- [ ] **DBOPT-05**: Server-side filtering works with ILIKE for text columns
- [ ] **DBOPT-06**: COUNT(*) query optimized or cached (< 50ms at 1000 rows)
- [ ] **DBOPT-07**: GORM slow query warnings eliminated (no queries > 100ms)

### Authentication (AUTH)

- [ ] **AUTH-01**: User can register with username and password
- [ ] **AUTH-02**: Password hashed with Argon2id (OWASP 2026 standard)
- [ ] **AUTH-03**: User can log in and receive JWT access token
- [ ] **AUTH-04**: Access token expires in 15 minutes
- [ ] **AUTH-05**: Refresh token stored in httpOnly cookie (7 days)
- [ ] **AUTH-06**: Silent token refresh happens automatically before expiration
- [ ] **AUTH-07**: User session persists across browser refresh
- [ ] **AUTH-08**: All GraphQL mutations require valid authentication
- [ ] **AUTH-09**: User can log out (clears tokens and cache)
- [ ] **AUTH-10**: TanStack Query cache scoped by user ID
- [ ] **AUTH-11**: Cache cleared on logout to prevent data leakage
- [ ] **AUTH-12**: Login/Register pages with form validation
- [ ] **AUTH-13**: Protected route guards redirect unauthenticated users

### Content Categories (CAT)

- [ ] **CAT-01**: 20 content categories available (Google NL taxonomy subset)
- [ ] **CAT-02**: Each content item can have one category (single-select)
- [ ] **CAT-03**: Category stored in lookup table (not enum) for future flexibility
- [ ] **CAT-04**: Category picker component in Add Video flow
- [ ] **CAT-05**: ActivityTable filterable by category
- [ ] **CAT-06**: Category badge displayed in content row
- [ ] **CAT-07**: Auto-categorization suggestion via Claude API (user confirms)
- [ ] **CAT-08**: Category statistics displayed (count per category)

### AG Grid Power Features (GRID)

- [ ] **GRID-01**: Toolbar above ActivityTable with filter/column controls
- [ ] **GRID-02**: "Clear all filters" button resets all column filters
- [ ] **GRID-03**: Column visibility picker shows/hides columns
- [ ] **GRID-04**: Multi-column sort enabled (Ctrl+click headers)
- [ ] **GRID-05**: Filter state persists in localStorage
- [ ] **GRID-06**: Column state persists in localStorage
- [ ] **GRID-07**: "Reset to defaults" button restores original layout
- [ ] **GRID-08**: CSV export button downloads visible data
- [ ] **GRID-09**: Keyboard shortcuts documented (Ctrl+Shift+C = clear filters)

### Discover Page (DISC)

- [ ] **DISC-01**: /discover route with YouTube search functionality
- [ ] **DISC-02**: Search input with 300ms debouncing
- [ ] **DISC-03**: Search results display thumbnail, title, channel, duration
- [ ] **DISC-04**: Filter by video duration (any, short, medium, long)
- [ ] **DISC-05**: Filter by upload date (any, hour, today, week, month, year)
- [ ] **DISC-06**: Sort by relevance, date, view count, rating
- [ ] **DISC-07**: "Add to Library" button on each search result
- [ ] **DISC-08**: Visual indicator for videos already in library
- [ ] **DISC-09**: Category grid for browsing YouTube categories
- [ ] **DISC-10**: Pagination with "Load More" button
- [ ] **DISC-11**: Skeleton loading states during search
- [ ] **DISC-12**: YouTube API quota usage displayed to user

## v1.2 Requirements (Deferred)

### Multi-Content-Type (MCT)

- **MCT-01**: Content model supports YouTube videos, books, articles, podcasts
- **MCT-02**: Shared columns: creator, published_at, description
- **MCT-03**: Type-specific columns: duration (videos/podcasts), page_count (books)
- **MCT-04**: Google Books API integration for book metadata
- **MCT-05**: RSS feed parsing for podcast metadata
- **MCT-06**: Open Graph extraction for article metadata
- **MCT-07**: Content type icon/badge in ActivityTable
- **MCT-08**: Add Book flow with ISBN or title search
- **MCT-09**: Add Article flow with URL paste
- **MCT-10**: Add Podcast flow with RSS URL or search

## v2.0 Requirements (Deferred)

### Social Features (SOC)

- **SOC-01**: User can comment on content items
- **SOC-02**: Comments displayed as threaded discussions (ltree)
- **SOC-03**: User can reply to existing comments
- **SOC-04**: Real-time comment updates via WebSocket subscriptions
- **SOC-05**: User can like/upvote comments
- **SOC-06**: User can flag comments for moderation
- **SOC-07**: AI-assisted moderation with Claude (toxic content detection)
- **SOC-08**: User receives notifications for replies
- **SOC-09**: Notification preferences (in-app, email)
- **SOC-10**: User can block other users

### AI Assistant (AI)

- **AI-01**: Jeeves sidebar panel accessible from any page
- **AI-02**: Perspective refinement: Jeeves helps articulate perspectives clearly
- **AI-03**: Streaming responses for real-time feedback
- **AI-04**: Challenge mode: Jeeves presents counter-arguments
- **AI-05**: Content discovery: Jeeves suggests related content
- **AI-06**: Summarization: Jeeves summarizes perspectives on content
- **AI-07**: Conversation history persists within session
- **AI-08**: Prompt caching for cost efficiency (< $0.02 per interaction)

---

## Out of Scope

| Feature | Reason |
|---------|--------|
| OAuth social login (Google, GitHub) | Deferred to post-v1.1 (complexity) |
| Email verification | Not critical for v1.1 MVP |
| Password reset flow | Requires email infrastructure |
| User profile pages | Deferred to v1.2 |
| Infinite scroll | Against "calm browsing" philosophy |
| Mobile app | v1 is responsive web only |
| Real-time notifications | Deferred to v2.0 with social features |
| Voice input for Jeeves | Experimental, deferred to v2.0+ |
| Custom user-defined categories | Deferred to v1.2 |
| Moderation dashboard | Deferred to v2.0 with social features |
